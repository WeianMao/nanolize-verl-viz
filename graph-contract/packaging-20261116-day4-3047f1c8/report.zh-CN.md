## 体积、相同行和防默写

| 度量 | 原版 | 交付版 | 保留比例 |
| --- | --- | --- | --- |
| 源码 token | 115,637 | 34,740 | 30.04% |
| 配置 token | 32,879 | 2,671 | 8.12% |
| 源码 + 配置 token | 148,516 | 37,411 | 25.19%（减少 74.81%） |
| 不含 Python 注释 / docstring | 104,803 | 37,192 | 35.49% |
| 物理源码行（辅助指标） | 14,592 | 4,666 | 31.98% |
| 公开定义文档覆盖 | 68.6% | 0% | 文档已明显减少 |

token 使用冻结的 tiktoken 0.12.0 / cl100k_base，按源码和配置文件独立求和，与模型消耗 token 不同。测试、文档等按原生规则排除，携带的 SPDX 表不计入两边的 token。50% 是建议目标，不是行为成功标准。

全部范围均保留，选中范围的原始体积也是 148,516 token：全原版缩减 74.81%，选中范围的重写缩减同为 74.81%，功能裁剪缩减为 0%。配置归因仍是文件层面的估计，不能证明语义完整保留。

缩减含三个基准样本的 22,696 token 和部分 CI / 文档配置删除。Python 注释 / docstring 从 15,799 / 27,914 token 变为 219 / 0；不能将这些减少都解释为算法压缩。benchmarks 和 docs 又缺有效叶级测试。

| 相同行 / 防默写记录 | 交付结果 |
| --- | --- |
| 原生 unchanged_percent | 23.4%：同路径的 37 个文件，长度至少 8 字符的去首尾空白行，按行长加权 |
| 函数体 / 语句重复度 original_overlap | 11%（原生取整）；比较 2,329 行，排除签名、导入、注释、docstring 等 |
| 超过函数阈值的条目 | 1 个：Specifier.prereleases，8 比较行，62% |
| 防默写退回 | 0 个文件、0 次退回 |
| 策略 | auto；全局阈值 40%；函数阈值 60%，至少 8 行；每文件最多退回 1 次 |

auto 的全局阈值未触发，所以单个函数超过 60% 没有导致退回。0 次退回是运行记录，不是没有记忆复现的证明。测试设计退回的 19 份提案不属于防默写退回。

首次实现源代码隔离；失败修复按默认设置向 4 次作者调用提供了 16 个失败叶节点、27 个原版生产文件的参考权限，不代表每个文件都被读取。另有 3 次调用获得 15 个用例的结构化断言值反馈。不能把全过程描述为始终没有接触原码或失败输出。
