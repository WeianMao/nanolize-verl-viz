如何浏览

删减对照按能力、状态或关键词筛选 43 个模块；每个模块都说明用途、保留理由、前后行数以及实际文件。展开“查看实际文件与核对依据”可查看路径及与原计划的差别。保留模块可直接进入对应代码图。

Graph / Tree默认进入同步训练文件。Graph 单击节点看详情，双击文件或类深入；支持缩放、拖动、分页和关系筛选。Tree 展开完整包含层级。搜索覆盖整张图，定位状态保存在地址中。

Graph 每页最多 48 个范围节点，另显示最多 12 个出向关联节点；页面显示完整分母，数据没有为排版而删去节点。Tree 导出覆盖当前筛选的完整包含树，Graph 导出当前页及关联节点。函数详情中保存了当前提交的开头源码摘录，最长 20 行。

图能说明什么

文件、类、函数和方法来自实际 Git 文件清单及 Python 语法树，包含嵌套声明和装饰器区间。包含、导入、调用候选及继承关系来自可静态解析的源码。动态注册、反射、外部依赖和运行时分派不一定能解析；这不是完整运行时调用图。

本页交付独立的静态 Graph / Tree 浏览器，沿用上一版视觉风格。不将它称为新的 LMA 原生导入或完整 UA 执行结果。模块保留状态也不是训练正确性或行为等价认证；既有验证结论不因生成可视化而升级。
